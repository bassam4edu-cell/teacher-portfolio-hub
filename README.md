# ملف الإنجاز المهني — بسام العنزي

**تحديث 2026-11-10:** واجهة عامة مبسطة بأربعة أقسام، وتقارير داخل عناصر الأداء، وقالب مطابق للمرجع، واتصال تحديث مباشر من هذه المساحة دون أدوات Lovable للاستخدام اليومي. [تفاصيل التنفيذ](docs/SIMPLIFICATION.md).

نظام شخصي عربي لمعلم اللغة الإنجليزية، مبني على مشروع Lovable الحالي باستخدام TanStack Start وReact وSupabase.

يتضمن تنظيم الشواهد حسب عناصر الأداء، مستهدفات توثيق قابلة للضبط، أصول الصور ونسخ الشواهد، قوالب تقارير وPNG وطباعة PDF بالعربية، جدولًا مدرسيًا، ودعوات خاصة للمراجعة. تجهيز المحتوى الذكي يتم خارج الموقع، ولا يشترط OpenAI API أو Lovable AI.

**الحالة الحالية:** فُعّلت قاعدة البيانات والصلاحيات بتاريخ 2026-11-09 بعد موافقة المالك، وهُيئت بيانات المعلم. نجح اختبار التكامل الإداري على القاعدة الفعلية داخل معاملة أُلغيت بالكامل. لا توجد شواهد تجريبية محفوظة. يلزم إنشاء حساب المالك وتأكيد البريد وتحديد فترة الملف قبل الاستخدام اليومي.
