# الدورات والتطوير المهني

الصفحة العامة: `#courses`. أضيفت إلى التنقل، مع عدد الدورات وإجمالي الساعات المعروفة وإجمالي الأيام منفصلًا. لا تحويل افتراضيًا بين الأيام والساعات، ولا احتساب مرفقات إضافية كدورات. يعاد التحميل عند إشارة التحديث الحالية أو كل 15 ثانية للصفحة المفتوحة.

تحفظ البيانات في `portfolio_courses`، والوثائق في `portfolio_course_documents`، والإصدارات السابقة في `portfolio_course_versions`. فُعّلت البنية الإضافية عبر أداة قاعدة Lovable بعد اجتياز الاختبارات المعزولة. اختُبرت الإضافة والقراءة ومنع التكرار بمفتاح مؤقت داخل معاملة إنتاج تم التراجع عنها بالكامل؛ لم تبق دورة تجريبية.

## استقبال دورة من المحادثة

تستخدم الأوامر مفتاح التكامل الحالي المحفوظ خارج المستودع. لا تحتاج إضافة الدورة بناء الموقع أو أدوات Lovable أو خدمة ذكاء اصطناعي داخل الموقع.

```bash
python -B scripts/portfolio-agent.py courses
python -B scripts/portfolio-agent.py course-import /tmp/course-package.json
python -B scripts/portfolio-agent.py course-document /tmp/document-id.json
```

الأمر الأخير يستقبل `{ "id": "document-uuid" }` ويعيد الملف للأيجنت المصرح فقط، بما في ذلك الأصل. لا تطبع الملف أو بياناته الحساسة للمحادثة.

```json
{
  "schema_version": 1,
  "request_id": "unique-course-request-id",
  "operation": "upsert",
  "course": {
    "id": "stable-course-uuid",
    "title": "عنوان الدورة كما ورد في الشهادة",
    "provider": "الجهة المقدمة",
    "execution_on": null,
    "date_label": "التاريخ كما ورد عند معرفته",
    "duration_value": 6,
    "duration_unit": "hours",
    "is_public": true,
    "source": "شهادة أرسلها المعلم في المحادثة"
  },
  "original": {
    "name": "original.pdf",
    "mime": "application/pdf",
    "base64": "BASE64",
    "sha256": "64 lowercase hex"
  }
}
```

لا تخترع عنوانًا أو جهة أو مدة أو تاريخًا. عند عدم معرفة المدة اترك `duration_value` و`duration_unit` بالقيمة null. الوحدة hours أو days فقط. `execution_on` تاريخ ميلادي ISO عند التحقق منه؛ يمكن حفظ التاريخ الهجري أو النصي كما ورد في `date_label` دون تخمين تحويل. ترتب التواريخ الميلادية المعروفة من الأحدث، ثم غير المحددة.

للنسخة العامة: أضف `public_copy` بنفس بنية الملف، مع `privacy_reviewed: true` بعد إعداد نسخة مستقلة تخفي الهوية ورقم الموظف والتواصل ورموز التحقق الحساسة عند وجودها. لا يحدث إخفاء تلقائي للبيانات عند الرفع. إن خلا الأصل من بيانات حساسة ويمكن نشره صراحةً: `publish_original: true` مع `privacy_reviewed: true`. رفع الأصل وحده يبقيه خاصًا. يمكن نشر بيانات الدورة دون وثيقة عامة حتى تجهيز النسخة المنقحة.

للتعديل أرسل نفس `course.id` و`course.version` الحالية؛ تحفظ النسخة السابقة. لتحديث الوثيقة أرسل أصلًا أو نسخة نشر جديدة؛ تبقى الملفات السابقة محفوظة. منع التكرار يعتمد على بصمة الأصل في كل الدورات، بما فيها تاريخ الأصول السابقة. تكرار الطلب نفسه يعيد النتيجة دون ازدواجية. لسحب الوثيقة العامة فقط أرسل `withdraw_document: true`. للأرشفة والاسترجاع استخدم operation بالقيمة archive أو restore مع معرف الدورة ونسختها.

## الإدارة والطباعة

بعد الدخول إلى مساحة المالك يوجد نموذج احتياطي بسيط لإضافة الدورة وتعديلها وإرفاق الأصل والنسخة العامة وأرشفتها واسترجاعها. الزائر لا يملك صلاحية كتابة أو قراءة الجداول الخاصة، وإتاحة الملف مفروضة عبر RPC وليس بإخفاء الأزرار. إلغاء نشر الدورة أو أرشفتها يسحب الوصول إلى وثيقتها العامة أيضًا. أسماء الملفات العامة عامة ولا تكشف اسم الملف الأصلي.

طباعة دورة واحدة أو السجل كاملًا إلى A4 بالعربية، مع اختيار إرفاق الشهادات. يحول PDF.js صفحات شهادات PDF إلى معاينات للطباعة داخل المتصفح؛ لا تعدل بايتات الأصل. تبقى نصوص جدول التقرير نصوصًا قابلة للقراءة. لا تستخدم خدمة PDF مدفوعة. تصدر الصفحات كاملة دون قص، مع ترقيم صفحات في المتصفحات الداعمة.

الحد التطبيقي للوثيقة 20 MiB، ولحزمة الاستيراد 60 مليون بايت. الملفات ضمن حدود حساب قاعدة البيانات والتخزين الحالي وليست سعة غير محدودة. لا اشتراك إضافيًا أو شحنًا تلقائيًا. قد تكون التقارير ذات الشهادات الكثيرة ثقيلة على ذاكرة الهاتف؛ يمكن طباعة كل دورة منفردة أو طباعة الجدول دون الوثائق.
