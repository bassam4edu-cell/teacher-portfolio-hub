# عرض الملف للزائر

بناءً على توجيه المالك في 2026-11-09، أصبحت النبذة والسيرة والرؤية والرسالة والقيم والأهداف والجدول المنظم وعناصر الأداء متاحة للقراءة دون تسجيل الدخول.

دالة `portfolio_public_view` تعرض حقول الملف المهنية المحددة فقط. لا تمنح الزائر أي كتابة أو إدارة، ولا تكشف جداول الإعدادات الخام أو مفاتيح التكامل أو بيانات المراجعين. أصل صورة الجدول لا يُنشر؛ الجدول المنظم يظهر بحصصه العشرين وحصة الانتظار، دون افتراض تاريخ سريان أو أوقات حصص.

حاول التغيير الأول توسيع العرض للشواهد المكتملة وأصولها. رفضت المراجعة الآلية نشر الأصول وتقارير الشواهد كاملة لاحتمال بيانات طلاب أو معلومات خاصة. لم تُطبّق الدوال المرفوضة. طُبق بديل محدود بالأقسام العامة التي حددها المالك؛ مكتبة الشواهد وأصولها تبقى وفق الصلاحيات الخاصة حتى تحديد المحتوى المسموح بنشره.

التحقق الفعلي:

- RPC عام دون جلسة أعاد الجدول: 21 تكليفًا، منها 20 تدريسًا وحصة انتظار واحدة.
- جداول الإعدادات والأصول الخام لا تعرض صفوفًا للمجهول.
- المجهول لا يملك إذن تنفيذ الدالة الإدارية.
- لا يُكشف مسار الصورة الأصلية في العرض العام.
- فُحص عرض الجدول للزائر في Chromium بمقاس 390×844 باستخدام رد HTTP الحقيقي، دون ظهور روابط الإدارة أو تمرير أفقي.

تُقرأ البيانات من القاعدة عند فتح الموقع وتحديثه؛ إضافة جدول جديد لا تتطلب تعديل الكود.
