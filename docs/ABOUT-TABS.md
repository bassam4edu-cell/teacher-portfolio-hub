# تبويبات عن المعلم

أضيفت ستة تبويبات عامة للقراءة، بروابط `#about/introduction` و`vision` و`ethics` و`policy` و`cv` و`objectives`. يدعم الشريط الجوال والتنقل بلوحة المفاتيح وفق RTL، ورجوع المتصفح وتقليل الحركة.

تحفظ النصوص الجديدة في `portfolio_settings.data.about` (introduction / ethics / policy / objectives). يسمح الإسقاط العام لهذه الحقول الأربعة فقط؛ أضيفت إلى دالة `portfolio_public_view` عبر أداة قاعدة Lovable في 2026-11-10. لم تتغير الجداول أو صلاحيات الكتابة أو حماية المرفقات. يحفظ المالك النصوص من «تبويبات عن المعلم»، أو عبر عملية settings الموجودة؛ يظل سجل نسخ الإعدادات محفوظًا.

تستخدم الرؤية والرسالة والقيم والسيرة والأهداف المهنية الحقول الحالية. أضيفت نصوص أولية للرؤية والرسالة والقيم إلى الحقول الفارغة فقط؛ لم تضف مؤهلات أو خبرات أو دورات غير موثقة.

ملخص الميثاق صياغة تعريفية مرتبطة بنسخة وثيقة وزارة التربية والتعليم (الطبعة الأولى 1427هـ) لدى جامعة أم القرى، وليس ادعاءً بأنها أحدث مدونة سلوك نافذة. ملخص السياسة مرتبط بمرجع «التعليم في المملكة» في وزارة التعليم. تظهر روابط المصادر بجوار كل ملخص.
