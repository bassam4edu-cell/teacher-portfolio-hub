# Standalone PDF witnesses

The owner explicitly requested the curriculum distribution as a witness only, with no activity report, and approved visitors opening/downloading its original PDF. `portfolio_import` stores the complete original privately and preserves its SHA-256. No row is added to `portfolio_publications` for a document-only witness.

Database functions applied through the Lovable database connector are recorded in `standalone-documents.sql` (not a generated migration). Anonymous/public reads require ALL of: evidence status `complete`, JSON boolean `data.document_only=true`, an explicit owner-set `data.public_document_asset_id` that matches a PDF attachment belonging to the same evidence, and an original. `portfolio_public_documents` returns selected metadata only. `portfolio_public_document(p_id)` accepts the evidence UUID and repeats the checks before returning original bytes. It does not accept a generic attachment UUID. Archiving, withdrawing the pointer, or changing the record away from complete removes public access. Neither function grants table access or public writes; the existing integration key controls the publication pointer.

To publish another original, import the evidence and PDF normally, then version-update its data with `document_only: true`, `document_pages: <verified page count>`, and `public_document_asset_id: <that evidence's selected PDF attachment UUID>`. Never guess the page count or designate an unrelated attachment. Public metadata reloads through the normal portfolio refresh; no rebuild is required for later document additions.

The frontend lists documents separately within their criterion and period, counts them as witness attachments, and leaves activity-report totals and the classroom gallery unchanged. Open/download actions fetch and verify the exact MIME, byte count, PDF signature and SHA-256 before handing a File to the browser. No synthetic title page, execution date, duration or outcomes are added to the original. File viewing depends on the device's native PDF handler; downloading remains available. Document originals are not rendered as `SimpleReport` activity pages.

The final printed portfolio lists each published original under its criterion with its title, verified page count, and a QR linking to `#criteria/<criterion>/document/<evidence UUID>`. This link focuses the corresponding witness card, where the visitor can preview/open/download the complete verified original. Print generation reads metadata and generates QR codes; it does not load or rasterize the original PDFs.

The existing key-protected `portfolio_import(jsonb,text)` function has a function-scoped `statement_timeout=60s` applied through the Lovable database connector to support unchanged larger PDFs within its existing 20 MiB per-file limit. The anonymous role's 3-second default, permissions, key validation, and all file-size/signature/hash checks are unchanged.
