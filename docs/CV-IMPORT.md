# السيرة المهنية العامة

استندت الإضافة بتاريخ 2026-11-10 إلى صورة السيرة التي أرسلها المالك. نُقلت المؤهلات الثلاثة، وخبرتا التدريس والمحاضرة، والرخص المهنية، والمشاركة بورقة بحثية، ومهارات التقنية والعمل الجماعي. لم تُضف تواريخ غير واضحة أو مدة خبرة محسوبة أو دورات غير مسماة.

لم تُنقل أرقام الاتصال أو البريد الشخصي أو العنوان التفصيلي أو المعدلات. لا تنشر صورة المصدر أو نسخة PDF الأصلية. احتُفظ باسم العرض المختصر الحالي. مستوى الرخصة «معلم خبير» محفوظ كمستوى للرخصة، دون افتراض الرتبة الوظيفية أو صلاحية الرخصة الحالية.

تحفظ السيرة في career بالأنواع qualification / experience / certification / research / skill، مع معرفات مستقرة ونسخ الإعدادات السابقة. تبقى السجلات ذات الأنواع السابقة ضمن «التطوير المهني والإنجازات». لا تغيير في صلاحيات الإدارة أو سياسة إسقاط بيانات التواصل من العرض العام.
