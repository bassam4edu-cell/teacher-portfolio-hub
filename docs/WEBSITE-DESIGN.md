# تحديث هوية واجهات الموقع

- غلاف شخصي بدرجات الكحلي والأخضر، باسم المعلم وصورة شاهد منشور فعلًا؛ يفتح الصورة والتقرير من المصدر الحالي دون تعديلها.
- ملخص بأعداد التقارير والعناصر والعناصر الموثقة محسوب من بيانات الفترة الحالية، دون نسب أو إنجازات مصطنعة.
- عرض غير متطابق لأحدث الممارسات، وعناصر أداء مرقمة، وروابط واضحة للجدول والدورات.
- هوية متناسقة لصفحات المعلم والسيرة والدورات والجدول، مع تمييز اليوم الحالي عندما يقع من الأحد إلى الخميس.
- حركة محدودة ودعم تقليل الحركة، وواجهة مصممة للشاشات الصغيرة والمتوسطة والكبيرة.

التنسيق الجديد في `experience.css` ويستهدف عناصر الموقع، دون تعديل ملفات القالب `SimpleReport.tsx` أو `simple-report.css` أو التصدير. بقيت التقارير والشهادات وواجهات التكامل والصلاحيات والبيانات كما هي. لا خدمات أو مكتبات أو صور مولدة إضافية.

التحقق يشمل التنقل والتبويبات وفتح الشواهد والشهادات والطباعة وPDF، وفحص العرض الفعلي بأحجام 320 و390 و768 و1024 و1440 بكسل. يبقى تحميل التقارير باستخدام القالب المعتمد نفسه.
