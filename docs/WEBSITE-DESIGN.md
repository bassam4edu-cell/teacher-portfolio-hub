# الهوية المرجعية لواجهات الموقع

اعتمد المالك مرجعًا بصريًا فاتحًا بزخارف هندسية عربية، وعناوين بترولية، وتفاصيل حجرية محايدة دون ذهبي.

- غلاف مركزي باسم المعلم، وزخارف أطراف مرسومة كأصل SVG محلي؛ لا نسخ لشعار الجهة أو بيانات فعالية المرجع.
- صورة من شاهد منشور فعليًا أسفل الغلاف، دون قص أو تعديل المصدر.
- صفوف مرقمة لعناصر الأداء بإطارات رفيعة، مع الأوزان والأعداد من بيانات الموقع الحالية.
- تنسيق متناسق للرئيسية، والمعلم والسيرة والتبويبات، والدورات، والجدول والتذييل.
- حركة خفيفة ودعم تقليل الحركة، وفحص أحجام 320 و390 و768 و1024 و1440 بكسل.

التنسيق في experience.css ويستهدف واجهات الموقع. لم تتغير ملفات قالب التقرير أو تصديره، أو الصور والشهادات أو قواعد البيانات والصلاحيات أو واجهات التكامل. تستمر طباعة التقارير بالقالب المعتمد نفسه. لا خدمات مدفوعة أو خطوط خارجية أو مكتبات إضافية.
