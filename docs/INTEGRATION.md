## الحالة والربط الفعلي

أمكن قراءة قاعدة المشروع عبر أداة Lovable المتصلة في هذه المحادثة. **لم تُطبَّق حزمة القاعدة بعد بسبب رفض المراجعة الآلية**؛ لذلك لم يُختبر إدخال حزمة في الإنتاج، ولا يصح الادعاء بأن الإرسال الآلي يعمل الآن.

بعد الموافقة وتطبيق `database-proposal.sql`:

1. يسجل المالك بالحساب المحدد ويؤكد بريده، ثم يضغط «تهيئة الملف» ويحدد فترة الملف والمستهدفات.
2. يجرى اختبار إنتاج واحد معلن كاختبار، مع أصل غير حساس، والتحقق من SHA-256 والنسخة وطلب مكرر وحساب غير مصرح. يؤرشف الاختبار بعده؛ لا يسجل كشاهد مهني مكتمل.
3. من هذه المحادثة، إذا بقي موصل Lovable متصلًا ومصرحًا للمشروع، يمكن للمساعد استدعاء `portfolio_admin_import` عبر أداة `query_database` على مشروع **379cc9dd-1e37-48b1-9421-9ee990363a78**. هذه دالة ذات صلاحية المستدعي، محظورة على `anon` و`authenticated`، ومخصصة للاتصال الإداري الحالي؛ لا تحتاج مفتاحًا في المحادثة. لا يتطلب ذلك تعديل الكود لكل شاهد أو استهلاك أرصدة بناء Lovable.
4. هذا الوصول **لا ينتقل تلقائيًا إلى كل محادثة ChatGPT**. يجب أن يكون الموصل نفسه حاضرًا ومسموحًا له. عند عدم توفره تُستخدم حزمة الاستيراد مؤقتًا.
5. بديل الموصل الإداري: مفتاح تكامل محدود المدة ينشئه المالك، يخزن في أسرار موصل HTTP، ويتحقق منه RPC. لا يطلب من المستخدم نسخ السر في المحادثة.

## حزمة الشاهد

```json
{
  "schema_version": 1,
  "request_id": "request-unique-stable-uuid",
  "operation": "create",
  "evidence": {
    "period_id": "id-from-portfolio-context",
    "title": "العنوان المستند إلى بيانات المعلم",
    "kind": "strategy",
    "criterion": 4,
    "target_id": null,
    "status": "draft",
    "data": {
      "subject": "اللغة الإنجليزية",
      "audience": "طلاب الصف الثالث الثانوي",
      "classification_reason": "سبب التصنيف المقترح وحدود الاستدلال من الصورة",
      "objective": "",
      "practice": "",
      "procedures": "",
      "assessment": "",
      "impact": "",
      "reflection": "",
      "source": "المعلومات التي قدمها المعلم والصور المستلمة",
      "additional_criteria": []
    }
  },
  "attachments": []
}
```

- `kind`: strategy، individual، assessment، technology، analysis، remedial، development، visit، parents، duty.
- `status`: draft، incomplete، complete، archived. المراجعة مستقلة في جدول المراجعات.
- التاريخ غير المعروف لا يرسل. `report_on` افتراضيًا يوم الإنشاء في الرياض؛ `execution_on` لا يُستنتج من الرفع.
- لا تصبح الحالة complete دون الهدف والممارسة وسبب التصنيف والمصدر. analysis وremedial يحتاجان أداة متابعة/تحليل أيضًا. اكتمال البيانات لا يثبت صحة الأثر أو اعتماد المدير.
- ملحق: `{ "name": "original.jpg", "mime": "image/jpeg", "base64": "...", "sha256": "64 lowercase hex" }`.
- نوع الملف يراجع من البايتات الأصلية وليس الاسم فقط. يُرفض اختلاف البصمة، ويُمنع تكرار SHA-256 للشاهد نفسه.
- الطلب كله في معاملة واحدة. نفس request_id والحزمة تعيد نفس النتيجة دون تكرار؛ اختلاف المحتوى مع المعرف نفسه يُرفض.

## إنشاء الحزمة مع الصور الأصلية

أضف إلى ملف manifest نفس بيانات الحزمة وقائمة `files` لمسارات الملفات الأصلية:

```json
{
  "schema_version": 1,
  "request_id": "unique-request-id",
  "operation": "attach",
  "evidence": { "id": "evidence-uuid", "version": 1 },
  "files": ["original.jpg"]
}
```

```bash
node scripts/build-package.mjs manifest.json ready-package.json
```

السكربت يقرأ البايتات كما هي، ويحسب البصمات، ولا يرفع أو يعدل الصور. استورد الناتج من «استقبال الشواهد» بعد معاينته.

## العمليات

| العملية  | البيانات                                                                                  |
| -------- | ----------------------------------------------------------------------------------------- |
| create   | شاهد منظم مع فترة، ونوع، وعنصر، وحالة، ومرفقات اختيارية                                   |
| update   | evidence.id وversion الحالي، والحقول المراد تحديثها؛ تحفظ النسخة السابقة                  |
| attach   | evidence.id وversion الحالي، وقائمة الصور/المرفقات الإضافية                               |
| archive  | evidence.id وversion؛ لا حذف دائم للأصول                                                  |
| restore  | evidence.id وversion؛ الاسترجاع كمسودة، مع الاحتفاظ بتاريخ الشاهد ونسخه                   |
| settings | version الحالية للإعدادات، وdata بالجزء المتغير: teacher / schedules / career / goals إلخ |
| progress | لا يحتاج evidence؛ يعيد نسبًا محسوبة، وعدد العناصر المشمولة، والمستهدفات الناقصة          |

تعديل التاريخ/نقل التصنيف يستعمل update. عند نقل العنصر، أرسل target_id مطابقًا أو null لتفادي ارتباط غير صحيح. العناصر الإضافية تحتاج reason، ولا تضاعف نسبة الاكتمال.

لإضافة جدول: أرسل schedules كاملة مع الإبقاء على النسخ السابقة. الأيام 0..4، وأرقام الحصص 1..15. لا تضف أوقاتًا غير معروفة. أرفق صورة الجدول الأصلية في حزمة settings، واجعل original_path في نسخته `integration/schedule/<sha256>`. تحفظ الصورة مستقلة دون تعديل.

## HTTP الآمن (بعد الربط والاختبار)

```http
POST <VITE_SUPABASE_URL>/rest/v1/rpc/portfolio_import
apikey: <publishable key>
Content-Type: application/json

{"p_package": {"schema_version":1,"request_id":"...","operation":"progress"}, "p_key":"<secret from connector vault>"}
```

المفتاح العلني لا يكفي للاستيراد. الدالة تتحقق من ملكية المستخدم المؤكد أو بصمة مفتاح فعال قبل الوصول للمحتوى. الرمز السري لا يحفظ في مستودع أو متصفح بشكل دائم. يمكن استدعاء الدالة بجلسة مالك Bearer بدل p_key. لا يوجد service_role في الواجهة أو الكود الجديد.

دالة `portfolio_progress` الداخلية ليست مكشوفة للمستخدم المجهول؛ يمر الاتصال عبر `portfolio_import` بعد التحقق. دوال إنشاء الدعوة/المفتاح والمراجعة تتحقق من الصلاحيات داخليًا، إضافة إلى RLS.

## المشاركة والخصوصية

- الدعوة مقيدة بالبريد المؤكد والنسخ الحالية للشواهد المختارة، والأقسام التي يختارها المالك فقط. لا يظهر الهاتف أو التواصل الخاص في المشاركة افتراضيًا.
- الإلغاء يمنع قراءات القاعدة الجديدة مباشرة. الملفات التي نزلها شخص مصرح له بالفعل لا يمكن سحبها من جهازه. الروابط الموقعة لمسار Storage صالحة ٦٠ ثانية؛ مسار الحزم يقرأ البايتات بعد تحقق RLS.
- لا تُحوّل الأصول إلى ملفات عامة. إذا لزمت نسخة منزوعة البيانات تنشأ كملف مشاركة مستقل ويظل الأصل محفوظًا؛ لا توجد أداة تنقيح آلية في هذه النسخة ولا داعي للادعاء بذلك.
- رابط المرفق في PDF يرجع للشاهد ويتطلب جلسة مصرحًا لها؛ لا تُضمّن رموز دعوة أو مفاتيح أو روابط موقعة مؤقتة في الملف المصدر.

لتمرير الحزمة إلى موصل Lovable الإداري، يمكن تجهيز استعلام آمن دون تنفيذ:

```bash
node scripts/build-admin-query.mjs ready-package.json import.sql
```

الأداة تستخدم محدد dollar-quote عشوائيًا غير موجود في المحتوى، ولا تضع نص الشاهد في سلسلة SQL غير مهربة. استخدم الاستعلام فقط على المشروع المحدد وبعد الموافقة وتطبيق القاعدة.
