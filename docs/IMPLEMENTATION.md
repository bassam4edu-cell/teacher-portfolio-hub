## القرارات التنفيذية

- إعدادات الملف تتضمن كيانات الفترات والمعايير والمستهدفات والأهداف والسيرة والجدول في JSONB منظم بمعرفات مستقرة ونسخ إعدادات محفوظة. الشواهد والمرفقات والنسخ والمراجعات والدعوات والطلبات والمفاتيح جداول مستقلة. يمنع تضخيم هيكل المشروع مع الاحتفاظ بترابط المعرفات والتحقق من الفترة والمستهدف.
- الحساب المسموح له بالملكية هو **bassam4edu@gmail.com**، استنادًا إلى حساب Lovable المتصل الذي يملك هذا المشروع. التسجيل وحده لا يمنح الإدارة، ويجب تأكيد البريد. يلزم تغيير صف `portfolio_owners` إداريًا إن اختار المالك بريدًا آخر.
- مشاركة خاصة مع تسجيل دخول بالبريد المدعو؛ لم تُضف روابط عامة مجهولة تكشف صور الطلاب. يمكن مشاركة زائر مدعو للقراءة فقط، أو مراجع للتعليق دون تعديل محتوى المعلم.
- الصور الواردة في حزم الاستيراد تُحفظ **ببايتاتها الأصلية** في جدول أصول محمي بـRLS. هذا يتيح مسارًا ذريًا من المساعد دون تسريب service_role أو إعادة بناء الموقع لكل شاهد. تخزين Base64 يضيف قرابة الثلث إلى الحجم؛ ليس تخزينًا مجانيًا بلا حدود. حاوية `portfolio-private` خاصة وجاهزة لمسارات التخزين المعتادة، لكن المستورد الحالي يستخدم الجدول الخاص لضمان ذرية الحزمة والبصمة.
- حد الملف ٢٠ MiB، والحزمة ١٠٠ MiB و٣٠ مرفقًا. هذه حدود التطبيق؛ قد تكون حدود النقل الفعلية للحساب/البوابة أقل. يوصى بحزم صغيرة وعمليات `attach` مستقلة للصور الكبيرة.
- النسخة الأولى تحفظ PDF عبر نافذة الطباعة في المتصفح: اختيار «حفظ بصيغة PDF» على A4، مع إيقاف رؤوس وتذييلات المتصفح. مستندات PDF المرفقة نفسها ليست مدمجة داخل PDF المجمع؛ يظهر رابط دائم للشاهد لتنزيل الأصل بعد تسجيل الدخول.
- PNG صفحات مستقلة بدقة مضاعفة؛ بعض المتصفحات تطلب السماح بتنزيل عدة ملفات. لا يُقص الأصل ولا يعاد توليده أو تغيير نسب أبعاده.
- لا توجد OpenAI API أو Lovable AI أو اشتراكات إضافية أو شحن تلقائي أو واتساب. لا تُشغّل أداة بناء Lovable المدفوعة. قراءة القاعدة والإدارة تستخدمان الاتصال الحالي.
- تأكدنا من أن خطة مساحة العمل الحالية هي Pro دون تعديلها. حدود الرصيد والتخزين والبناء لا تعرضها أدوات Lovable المتاحة بصورة موثوقة؛ تُراجع من لوحة الحساب قبل الاستخدام المكثف. لم يُدَّعَ أنها غير محدودة.

## مرجع الأداء

تحققنا من صفحة الوزارة والدليل المرتبط بها، وليس من معايير الرخصة المهنية:

- الوثيقة: الدليل الإرشادي لإدارة الأداء الوظيفي لشاغلي الوظائف التعليمية.
- الجهة: وزارة التعليم. الإصدار الثاني. نموذج تقييم أداء المعلم.
- صفحة المرجع: https://www.moe.gov.sa/ar/reference-and-support/employee-portal/performance
- الدليل: https://www.moe.gov.sa/media/uploads/19/193f6dcdea50d6dcfb28aef8a14434f64df8b2c4f628c7f8c0303345bdcc4b49.pdf
- تاريخ التحقق: 2026-11-09.
- الأوزان التسعة ١٠٪ والعنصران ٨ و٩ بوزن ٥٪. التسمية في الدليل للعنصر ٨ «تهيئة بيئة تعليمية»، وللعنصر ١١ «تنوع أساليب التقويم». صُحح النص المستخرج من PDF بدل نسخ أخطاء OCR.
- الاكتمال نسبة توثيق داخلية: مستهدفات مكتملة مميزة ÷ المستهدفات المحددة. المتوسط العام يشمل العناصر ذات المستهدف فقط، ولا يدخل وزن التقييم الرسمي في الحساب.

## البيانات الفعلية الناقصة

لم تُنشأ شهادات أو خبرات أو نتائج أو أعوام دراسية أو شواهد افتراضية. لم تُستلم صور التعلم الفردي الموجه وتعليم الأقران والتعلم التعاوني والتغذية الراجعة أو صورة الجدول أو مرجع التصميم الجرافيكي. لا يوجد شعار وزارة أو ختم أو توقيع مصطنع. تبقى هذه الأجزاء بلا محتوى حتى توفر بياناتها.

## تشغيل واختبار محلي

```bash
npm ci
npm run typecheck
npm run test
npm run test:db
npm run build
npm run dev -- --host 0.0.0.0 --port 5173
# في طرفية ثانية بعد تثبيت Chromium:
npx playwright install chromium
npm run test:browser
```

اختبار القاعدة يستخدم PostgreSQL WASM محليًا عبر PGlite؛ يحاكي auth/storage والأدوار، ويستخدم SHA-256 المدمج بديلًا لاختبار pgcrypto غير المتاح في WASM. الإنتاج يستخدم pgcrypto الحقيقي. اختبار المتصفح يستخدم ردود Supabase معزولة؛ لا يثبت وجود ربط إنتاجي. لا تُرفع ملفات الاختبار أو شواهده إلى قاعدة المستخدم.
