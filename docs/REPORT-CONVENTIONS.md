# تفضيلات تقارير الشواهد الصفية

اعتمد المالك لهذه التقارير الحالية والمستقبلية:

- مدة التنفيذ: «حصة دراسية».
- المستفيدون: «طلاب الصف الثالث الثانوي»، دون عنوان «العدد» أو عبارة «العدد غير محدد».
- عرض تاريخ التنفيذ نفسه دون لاحقة «تقديري».

تطبق هذه القواعد مركزيًا في قالب التقرير وفي PDF الناتج منه، بما يشمل السجلات المنشورة سابقًا. تستخدم عمليات إعداد التقارير الجديدة `reportDefaults` عند بناء بياناتها. لا تغيّر هذه التفضيلات مدد الدورات التدريبية أو وثائقها الأصلية.

لم تُعدّل التواريخ السابقة أو الصور أو مصادر المعلومات؛ يبقى مصدر التاريخ وأي وصف داخلي لكونه مختارًا وفق توجيه المالك محفوظين في السجل. لا يُستنتج تاريخ تنفيذ جديد من تاريخ رفع صورة. ملفات PDF القديمة المحفوظة كنسخ سابقة لا تُستبدل؛ زر تحميل PDF الحالي يبني التقرير بالقالب المحدث.

## صياغة العنوان والأهداف وخطوات التنفيذ

اعتمد المالك بتاريخ 2026-11-11 القواعد التالية لكل التقارير الجديدة، وطُبقت على التقارير الأربعة المنشورة:

- عنوان التقرير يسمّي الاستراتيجية أو الممارسة التعليمية بصورة عامة، مثل «توظيف استراتيجية التعلم بالأقران في تدريس اللغة الإنجليزية».
- الأهداف أهداف تعليمية عامة للاستراتيجية، وليست وصفًا للأشخاص أو الأدوات أو النصوص التي تظهر في الصور.
- «خطوات التنفيذ / الوصف» يشرح منهج الاستراتيجية وتسلسلها التعليمي باختصار، دون سرد بصري من نوع «تظهر الصورة» أو ذكر عنوان شريحة أو درس لمجرد ظهوره في الشاهد.
- الصور الأصلية تُرفق كشواهد داعمة. لا تُغيّر الصور ولا يُستنتج منها تحسن النتائج.
- يُصاغ الوصف العام بصيغة تفسيرية، مثل «تقوم الاستراتيجية على… تبدأ خطواتها…»، ولا يُقدَّم بوصفه إثباتًا لتنفيذ خطوات إضافية لم يؤكدها المعلم. تبقى تفاصيل المصدر وحدود الاستدلال في السجل الداخلي.
- عند تعديل تقرير قائم، تُحدَّث حقول title وdata.practice وdata.procedures وdata.objective في سجل الشاهد مع حفظ نسخته، ثم title وreport.description وreport.objectives في نسخة النشر عبر التكامل. تُحفظ المرفقات والتاريخ والتصنيف وأي بيانات مؤكدة أخرى.
- لا تضف نتائج أو أدوات تقويم أو أعدادًا غير موثقة لتجميل الصياغة.

تُحدّث التقارير من خلال قاعدة البيانات وواجهة التكامل؛ لا تحتاج إعادة بناء الموقع أو تعديل قالب التقرير لكل شاهد جديد.
