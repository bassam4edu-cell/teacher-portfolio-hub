# تفضيلات تقارير الشواهد الصفية

اعتمد المالك لهذه التقارير الحالية والمستقبلية:

- مدة التنفيذ: «حصة دراسية».
- المستفيدون: «طلاب الصف الثالث الثانوي»، دون عنوان «العدد» أو عبارة «العدد غير محدد».
- عرض تاريخ التنفيذ نفسه دون لاحقة «تقديري».

تطبق هذه القواعد مركزيًا في قالب التقرير وفي PDF الناتج منه، بما يشمل السجلات المنشورة سابقًا. تستخدم عمليات إعداد التقارير الجديدة `reportDefaults` عند بناء بياناتها. لا تغيّر هذه التفضيلات مدد الدورات التدريبية أو وثائقها الأصلية.

لم تُعدّل التواريخ السابقة أو الصور أو مصادر المعلومات؛ يبقى مصدر التاريخ وأي وصف داخلي لكونه مختارًا وفق توجيه المالك محفوظين في السجل. لا يُستنتج تاريخ تنفيذ جديد من تاريخ رفع صورة. ملفات PDF القديمة المحفوظة كنسخ سابقة لا تُستبدل؛ زر تحميل PDF الحالي يبني التقرير بالقالب المحدث.
