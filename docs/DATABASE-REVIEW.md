# التغيير المطلوب مراجعته قبل تطبيق القاعدة

الحزمة المقترحة: [database-proposal.sql](database-proposal.sql). **لم تُطبّق** بسبب رفض المراجعة الآلية للتغيير الأمني الواسع. جرى اختبارها على قاعدة PostgreSQL محلية معزولة؛ لا يغني ذلك عن اختبار الإنتاج بعد الموافقة.

التغييرات المحددة:

1. إنشاء جداول للملف والشواهد والأصول والنسخ والإعدادات والدعوات والمراجعات وطلبات الاستيراد والمفاتيح؛ دون حذف جدول `achievements` أو سجلاته.
2. تقييد قراءة الإنجازات القديمة بالمالك بدل القراءة العامة. عند الفحص كان العدد صفرًا.
3. تحديد ملكية الملف لحساب `bassam4edu@gmail.com` بعد تسجيله وتأكيد البريد. الحسابات الأخرى لا تكتسب الإدارة بالتسجيل.
4. تفعيل RLS للشواهد والأصول، وحاوية Storage خاصة، ومنع تعديل سجل النسخ أو تزوير مراجعة المدير من حساب المعلم.
5. دعوات مقيدة ببريد المراجع والشواهد والأقسام ومدة صلاحية. الإلغاء يمنع الوصول الجديد. لا توجد مشاركة مجهولة لصور الطلاب.
6. إنشاء دوال SECURITY DEFINER مضبوطة الصلاحيات والمسار للتحقق من الملكية والمشاركة والاستيراد وحفظ النسخ. دالة الاستيراد HTTP متاحة لدوري anon/authenticated **لكنها ترفض الطلب قبل أي قراءة أو كتابة دون جلسة مالك مؤكدة أو مفتاح خاص فعال**. وجود publishable key وحده لا يمنح الوصول. المفاتيح مخزنة كبصمات SHA-256 وتقبل الإلغاء والانتهاء.
7. مدخل إداري منفصل `portfolio_admin_import` ممنوع على أدوار المتصفح ومخصص لموصل Lovable الإداري الموجود. لا مفاتيح service_role في الواجهة أو المستودع.
8. الشواهد لا تستلزم تعديل الكود أو إعادة البناء. حزمة البيانات والمرفقات في معاملة واحدة، مع منع تكرار request_id والتحقق من البايتات والبصمة.

لا تتضمن الموافقة شراء خدمة، أو زيادة خطة، أو تشغيل Lovable AI، أو نشر الموقع للعامة. بعد التطبيق يلزم اختبار حفظ فعلي ومراجعة بصلاحية منفصلة؛ لا تُعلن النسخة مكتملة قبل ذلك.

## نتيجة التحقق المحلي

- TypeScript والبناء الإنتاجي: ناجحان.
- ١٢ اختبارًا للوحدات والمسارات والحسابات والتحقق من البيانات.
- ٤٢ فحصًا محليًا لقاعدة PostgreSQL والصلاحيات، بما في ذلك إلغاء المفاتيح، ومنع تضخيم المستهدفات، والنسخ السابقة، والمشاركة المقيدة.
- ١١ فحص متصفح باستخدام خدمة Supabase معزولة لاختبار الواجهة؛ لا اتصالات كتابة بالإنتاج.
- تقرير اختبار عربي: ٣ صفحات A4، نص قابل للاستخراج، وخط مضمن، وصورة PNG بدقة مضاعفة دون قص الأصل.
- فحص 390×844 و1440×1000 دون تمرير أفقي، مع قائمة جوال وعرض يومي للجدول.
- lint: لا أخطاء؛ ستة تحذيرات Fast Refresh في مكونات UI الأصلية.
- اختبار Safari على آيفون فعلي، واختبار موصل الإنتاج: متبقيان.
